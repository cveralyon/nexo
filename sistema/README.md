# Sistema

Esta carpeta reúne el protocolo, las reglas, las plantillas y las comprobaciones opcionales de Nexo.

- [Cómo usar Nexo](como-usar-nexo.md) define el flujo cotidiano de consulta, actualización y publicación.
- [Convenciones](convenciones.md) define identidad, metadatos, historia y enlaces.
- [Guía de clasificación](guia-de-clasificacion.md) ayuda a elegir una sede principal.
- [Archivos originales](archivos-en-drive.md) explica cómo conservar y enlazar documentos.
- [Empezar](empezar.md) guía la preparación de una copia privada.
- [Plantilla de nota](plantillas/nota.md), [plantilla de proyecto](plantillas/proyecto.md) y [plantilla de decisión](plantillas/decision.md) ofrecen puntos de partida.

## Utilidades opcionales

- [Validador estructural](scripts/validate_nexo.py) revisa estructura, metadatos y enlaces locales.
- [Dependencias de desarrollo](requirements-dev.txt) prepara la comprobación con Python 3.12.
- [Pruebas del validador](tests/test_validate_nexo.py) y [pruebas de aceptación](tests/test_acceptance.py) cubren casos sintéticos.
- [Workflow manual](../.github/workflows/validate.yml) permite ejecutar las comprobaciones desde GitHub Actions cuando se solicita de forma explícita.
- [Verificación de la base pública](verificacion.md) describe la evidencia de esta distribución.

Estas utilidades son ayudas opcionales. No sustituyen la lectura de fuentes ni acreditan la veracidad de una nota.
