# Empezar

1. Usa esta base como plantilla y crea un repositorio privado. No guardes memoria personal en un fork público.
2. Trabaja siempre sobre tu repositorio privado. Puedes editar desde GitHub, un editor, un conector con escritura o un clon local. Si usas terminal, clonar el repositorio es una opción y no un requisito.
3. Revisa [START_HERE](../START_HERE.md), [cómo usar Nexo](como-usar-nexo.md) y las [convenciones](convenciones.md).
4. Crea una nota desde la [plantilla](plantillas/nota.md), genera un UUID v4 y guárdala en el ámbito de su propósito principal.
5. Añade un enlace descriptivo desde el README del ámbito.
6. Publica el cambio y lee el archivo desde el repositorio remoto para comprobarlo.

Empieza con una nota real. No crees subcarpetas vacías ni intentes diseñar por anticipado todo el árbol personal. Las subdivisiones aparecen cuando el contenido las necesita.
