# Bandeja

Esta carpeta recibe temporalmente asuntos cuya sede todavía no está clara. No es un archivo permanente ni una categoría adicional.

Antes de añadir algo, busca si el tema ya existe. Si entra por la bandeja, registra el contexto mínimo para clasificarlo y muévelo a su ámbito cuando su propósito principal sea evidente. Conserva el mismo identificador al mover la nota y actualiza los enlaces que apunten a ella.

La [guía de clasificación](../sistema/guia-de-clasificacion.md) ayuda a elegir una sede. Una bandeja vacía es el estado esperado.
