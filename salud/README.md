# Salud

Portada para salud física y mental, consultas, exámenes, tratamientos, alimentación, entrenamiento y descanso.

Añade aquí enlaces descriptivos a las notas reales del ámbito cuando las crees. Los documentos originales permanecen en sus carpetas existentes. Cada examen, nueva emisión y corrección conserva su propio archivo y su enlace directo.
