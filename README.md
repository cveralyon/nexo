# Nexo Personal Brain

Nexo Personal Brain es una base reutilizable para mantener una memoria personal privada en Markdown. Organiza el conocimiento por ámbitos de vida, conserva una nota vigente por tema y permite que una persona o una herramienta lea solo el contexto necesario.

El repositorio público contiene únicamente la arquitectura, las guías, las plantillas y las comprobaciones opcionales.
## Crear tu Nexo privado

La opción recomendada es usar este repositorio como plantilla en GitHub y elegir **Private** al crear el repositorio nuevo. Sigue la [documentación oficial para crear un repositorio desde una plantilla](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template).

Un fork de un repositorio público sigue siendo público. Úsalo solo para contribuir mejoras genéricas a esta base y nunca para guardar memoria personal. GitHub explica ese modelo en [About forks](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/about-forks).

Después de crear tu copia privada, abre [START_HERE](START_HERE.md), revisa [cómo usar Nexo](sistema/como-usar-nexo.md) y crea la primera nota con una [plantilla](sistema/plantillas/nota.md).

## Ámbitos de vida

- [Perfil](perfil/README.md), identidad, valores, preferencias y autoconocimiento.
- [Salud](salud/README.md), cuidado físico y mental, consultas, exámenes y tratamientos.
- [Relaciones](relaciones/README.md), pareja, familia, amistades, comunidad y vida social.
- [Trabajo](trabajo/README.md), carrera, proyectos profesionales, equipos y oportunidades.
- [Finanzas](finanzas/README.md), presupuesto, cuentas, inversiones, impuestos y administración financiera.
- [Hogar](hogar/README.md), vivienda, movilidad, bienes, servicios y trámites cotidianos.
- [Tecnología](tecnologia/README.md), dispositivos, software, cuentas y proyectos tecnológicos personales.
- [Aprendizaje](aprendizaje/README.md), libros, cursos, habilidades e investigación reutilizable.
- [Ocio y viajes](ocio-y-viajes/README.md), viajes, aficiones, celebraciones y experiencias recreativas.
- [Ideas y futuro](ideas-y-futuro/README.md), visión de vida, escenarios, decisiones de rumbo e ideas transversales.

Cada README es una portada. Añade allí enlaces a las notas reales del ámbito cuando las crees. No pongas metadatos de contenido en las portadas.

## Principios

- Cada tema tiene una sede principal y una identidad estable.
- Las notas son documentos vivos. Se actualiza la nota vigente en lugar de crear una por conversación.
- La lectura es selectiva. Se empieza por un índice y una o dos notas.
- Los originales permanecen en sus carpetas existentes de Drive u otro archivo documental. Nexo conserva contexto y enlaces.
- Cada examen, emisión y corrección conserva su propio archivo. Una corrección no elimina el original.

El contenido temporal puede entrar por [_bandeja](_bandeja/README.md). Las reglas y utilidades están en [sistema](sistema/README.md).
